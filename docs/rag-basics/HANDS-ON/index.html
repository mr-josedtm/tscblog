HANDS-ON!

Vamos a construir un RAG sencillo usando Python y algunas librerías populares.

Requisitos previos​

  • Git.
  • Cuenta en GitHub.
  • Python 3.8 o superior instalado.
  • PyCharm, VSCode o cualquier IDE de tu preferencia.
  • Cuenta en OpenAI (u otro proveedor de LLM).

Frameworks​

  • Streamlit
  • Langchain

Estructura del proyecto​

Desde un terminal y clona el repositorio del taller:

git clone https://github.com/mr-josedtm/BASIC_RAG_WORKSHOP.git

El proyecto tiene la siguiente estructura:

BASIC_RAG_WORKSHOP/
├── README.md
├── requirements.txt
└── src/

Hagamos foco en los archivos dentro de la carpeta src/:

src/
├── .streamlit/
│   └── config.toml
├── assets/
│   └── logo.png
├── app.py
├── chat.py
├── prompt_templates.py
├── utils.py
└── wizard.py
  • .streamlit/config.toml: Configuración de Streamlit, de momento solo estamos definiendo el tema por defecto.
  • assets/: En este dicetorio guardamos todos los recursos estáticos que usa la aplicación. Como imágenes, íconos, etc.
  • app.py: Archivo principal de la aplicación Streamlit.
  • chat.py: Aquí definimos la lógica del RAG, incluyendo la carga de documentos, la creación del vector store, y la configuración del agente.
  • prompt_templates.py: Plantillas de los prompts utilizados en función del tipo de documento e idioma. Con esto conseguimos que las respuestas sean más precisas y adaptadas al contexto.
  • utils.py: Funciones utilitarias para ayudar en diversas tareas, principalemente relacionadas con la manipulación de documentos.
  • wizard.py: Es el componente visual encargado de preparar la aplicación para cargar los documentos antes de iniciar la conversación.

Configuración del entorno​

Abre tu IDE y carga el proyecto.

Crea un entorno virtual para aislar las dependencias del proyecto:

python -m venv ./.venv

Activa el entorno virtual:

  • En Windows:

    .\.venv\Scripts\activate

  • En macOS/Linux:

    source .venv/bin/activate

Instala las dependencias necesarias:

pip install -r requirements.txt

o

python -m pip install -r requirements.txt

si pip no está configurado como comando global.

Arranca el proyecto para asegurarte de que todo está funcionando correctamente.

cd ./src
streamlit run app.py
info

Si usas PyChar, asegúrate de configurar el intérprete del proyecto para que use el entorno virtual que acabas de crear. Además, crea una para arrancar la aplicación. Selecciona "Add Configuration..." en la esquina superior derecha, luego haz clic en el botón "+" y selecciona "Python". Configura el módulo como streamlit y en "Parameters" añade run app.py. Finalmente, selecciona el entorno virtual como intérprete.

Implementación del RAG​

Step 1: Dividir el texto en chunks​

Lo primero que necesitamos hacer tras cargar el documento, es dividirlo en chunks:

def load_document_to_llm(document, doc_format: str):
    if doc_format == PDF_FORMAT:
        raw_text = _get_pdf_text(document)
    elif doc_format == CSV_FORMAT:
        raw_text = _csv_to_text(document)
    else:
        raise ValueError(f"Formato de documento no soportado: {doc_format}")
    
    chunks = _get_text_chunks(raw_text)
def _get_text_chunks(raw_text: str) -> list[str]:
    splitter = RecursiveCharacterTextSplitter(
        chunk_size=1000,
        chunk_overlap=200,
        add_start_index=True
    )
    chunks = splitter.split_text(raw_text)
    print(f"INFO: Texto dividido en {len(chunks)} chunks")
    return chunks

Step 2: Crear la vector store​

Una vez hemos dividido nuestro text en chunks, vamos a almacenarlo en la vector store.

En este caso usaremos FAISS

def _get_vectorstore(text_chunks: list[str]) -> FAISS:
    embeddings = OpenAIEmbeddings()
    vectorstore = FAISS.from_texts(texts=text_chunks, embedding=embeddings, docstore=InMemoryDocstore())
    return vectorstore

Como vemos, estamos usando OpenAIEmbeddings para representar nuestros vectors y nuestra base de datos será en memoria

tip

Este enfoque no es production-ready, en una aplicación productiva utilizaríamos una base de datos con capacidades vectoriales como PostgreSQL

Para poder utilizar la base de datos con nuestro modelo a través de Lanchain necesitamos definir la base de de datos como una Tool del modelo.

def _make_vector_search_tool(vectorstore):
    @tool("search_docs", return_direct=False)
    def search_docs(query: str) -> str:
        """Busca información relevante en el documento cargado."""
        docs = vectorstore.similarity_search(query, k=5)
        return "\n\n".join(d.page_content for d in docs)
    return search_docs

Step 3: Creación del agente​

La última piza que falta en la arquiectura de nuestro RAG es el agente.

def _create_in_memory_checkpointer():
    return InMemorySaver()
def _create_agent_with_memory(tools):
    checkpointer = _create_in_memory_checkpointer()
    model = ChatOpenAI(model="gpt-4o-mini", temperature=0.0)
    agent = create_agent(
        model=model,
        tools=tools,
        checkpointer=checkpointer
    )
    return agent

Step 4: Integración del chat​

Completamos la integración de la vector store y agente y lo almacenamos el estado para poder usarlo repetidamente:

def load_document_to_llm(document, doc_format: str):
    if doc_format == PDF_FORMAT:
        raw_text = _get_pdf_text(document)
    elif doc_format == CSV_FORMAT:
        raw_text = _csv_to_text(document)
    else:
        raise ValueError(f"Formato de documento no soportado: {doc_format}")

    chunks = _get_text_chunks(raw_text)
    vectorstore = _get_vectorstore(chunks)
    search_tool = _make_vector_search_tool(vectorstore)

    agent = _create_agent_with_memory(tools=[search_tool])

    st.session_state.agent = agent
    st.session_state.thread_id = str(uuid4())
    st.session_state.messages = []

Definimios, haciendo uso de Streamlit el manejo de los mensages usuario/agente para representarlos:

def chat_view(init_prompt: str):

    st.title("💬 Chat")
    st.caption("🚀 Developed by JDTorrano")

    agent = st.session_state.agent
    config = {"configurable": {"thread_id": st.session_state.thread_id}}

    if not st.session_state.messages:
        init_sys_message = SystemMessage(content=init_prompt)
        input_dict = {"messages": [init_sys_message]}
        response = agent.invoke(input_dict, config)
        history = response.get("messages") or []

        last_content = ""
        if history:
            last = history[-1]
            last_content = getattr(last, "content", str(last))
        else:
            last_content = str(response)
        st.session_state.messages.append({"role": "assistant", "content": last_content})

    for msg in st.session_state.messages:
        st.chat_message(msg["role"]).write(msg["content"])


    if prompt := st.chat_input("Escribe tu pregunta aquí..."):
        st.session_state.messages.append({"role": "user", "content": prompt})
        st.chat_message("user").write(prompt)

        user_msg = HumanMessage(content=prompt)
        input_dict = {"messages": [user_msg]}
        response = agent.invoke(input_dict, config)

        history = response.get("messages") or []
        answer = ""
        if history:
            last = history[-1]
            answer = getattr(last, "content", str(last))
        else:
            answer = str(response)

        st.session_state.messages.append({"role": "assistant", "content": answer})
        st.chat_message("assistant").write(answer)
